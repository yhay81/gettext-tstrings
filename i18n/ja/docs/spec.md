# 仕様

このページを読まなくてもライブラリは使えます。日常的な使い方は
[チュートリアル](tutorial.md)と[ガイド](guide.md)で説明しています。このページは
ツール作者向けです。このライブラリが実装する規約は、小さく安定した契約として
文書化されています。これにより、抽出器、IDE、型チェッカー、将来の`pygettext`など、
別の実装も同じ規約を対象として相互運用できます。同じルールをその理由とともに、
そして参照実装がそれをどう実行しているかも含めて知りたい場合は、まず
[動作原理](internals.md)をお読みください。

[仕様v1を読む :material-arrow-right:](https://github.com/yhay81/gettext-tstrings/blob/main/SPEC.md){ .md-button .md-button--primary }

## ひと目で分かるルール { #the-rules-in-one-screen }

**msgid** は、ソース順のリテラル部分と、補間ごとの `{name}` トークンを連結した
ものです。リテラルの波括弧はエスケープされます（`{` は `{{` になります）。
名前は単純なプレースホルダー名でなければなりません。つまり、
`str.isidentifier()` が真で、Pythonキーワードではない名前です。変換指定と
フォーマット指定はmsgidに含めず、アプリケーション側で管理します。

| t-string | msgid |
| --- | --- |
| `t"Hello {name}"` | `Hello {name}` |
| `t"Total: {amount:,.2f}"` | `Total: {amount}` |
| `t"Config {{raw}} is {value}"` | `Config {{raw}} is {value}` |
| `t"Hello {user.name}"` | *拒否 — 単純な名前ではない* |

**翻訳**が有効なのは、単独の `{name}` プレースホルダーだけを含み、必須の名前が
すべて1回以上現れ、許可された集合にない名前が存在しない場合です。並べ替えと
繰り返しは意図的に制限しません。どちらも対象言語の文法上必要になる場合があります。

複数形では、*許可*される名前は両分岐の和集合、*必須*の名前は積集合です。そのため
`t"One file"` と `t"{n} files"` の組み合わせでは、どちらの翻訳形でも `n` を
利用できますが必須ではありません。対象言語の複数形規則がソース言語と異なっても
対応できます。

**空のmsgid**は検索しません。gettextがカタログのメタデータヘッダー用に予約して
いるためです。

## 適合性 { #conformance }

[`conformance/v1.json`](https://github.com/yhay81/gettext-tstrings/blob/main/conformance/v1.json)
は、同じ文書の機械可読版です。t-stringの静的構造からmsgidへの対応と、msgidと
カタログパターンからレンダリング結果または拒否への対応を収録しています。

すべてのケースを再現する実装は、**仕様v1に適合**します。ケースに含まれるのは、
導出されたmsgid、受理・拒否されるパターン、レンダリング結果という仕様で定義された
要素だけです。エラーメッセージや例外型には依存しないため、他言語の実装でもそのまま
実行できます。

補間はPythonソースではなく、構造として記述します。

```json
{
  "spec": "2.2",
  "name": "format spec stays out of the msgid",
  "source": [
    "Total: ",
    {"expression": "amount", "value": 1234.5, "format_spec": ",.2f"}
  ],
  "msgid": "Total: {amount}"
}
```

リファレンス実装は自身のテストスイートの一部として適合性テストを実行するため、
文書とコードのずれを気付かないまま残すことはありません。

## バージョニング { #versioning }

これは仕様v1です。msgidの導出または翻訳検証に後方互換性のない変更を加える場合は、
バージョンを上げ、既存ファイルと並べて新しい`conformance/vN.json`を提供します。
導出されるmsgidも受理されるパターンも変えない補足説明では、バージョンを上げません。
